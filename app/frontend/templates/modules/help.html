Help: показатели и формулы

На этой странице собраны все ключевые метрики интерфейса и их формулы в пользовательском виде.

Все PnL в quote-валюте (например, USDC/USDT), все APR в процентах годовых (%).

1) Обозначения
Total quote (Q)Общий объём капитала позиции в quote-валюте.
PnL quoteПрибыль/убыток в quote-валюте.
HoldSec (T)Время удержания позиции в секундах.
SecondsPerYear31,536,000 (365 * 24 * 60 * 60).
base_priceБазовая цена пары для пересчёта base в quote.
open_filled_quote_unitsОбъём в quote-единицах, фактически захеджированный при открытии.
2) Базовые формулы
APR (%) (PnL_quote / Q) * (31,536,000 / T) * 100
PnL (%) (PnL_quote / Q) * 100
Runtime (sec) (finished_at_ms - started_at_ms) / 1000
3) Gas/Costs как компонент PnL
Показатель Формула Что означает
Costs PnL quote costs_quote = -(gas_paid_quote + swap_cost_quote) Компонент PnL для издержек; обычно отрицательный (убыток).
Gas paid quote gas_paid_quote = gas_paid_eth * valuation_price Пересчёт on-chain gas из ETH в quote.
Gas paid eth gas_mint_eth + gas_decrease_eth + gas_collect_eth Сумма gas по mint/decrease/collect.
Swap cost quote rebalance_fee_quote (если есть rebalance order), иначе 0 Комиссия исполнения ребаланса.
Total gas/costs PnL quote (Dashboard) sum(costs_quote) Сумма PnL-компонента издержек по всем run (обычно отрицательная).
4) Декомпозиция PnL на итерации
Показатель Формула Что означает
DEX price PnL dex_realized_il_quote = (decrease_base * valuation_price + decrease_quote) - (mint_base * valuation_price + mint_quote) Результат ценового движения LP-позиции.
Fees received quote (collect_quote - decrease_quote) + (collect_base - decrease_base) * valuation_price Чистые LP-комиссии сверх возвращённого principal.
CEX PnL quote cex_pnl_quote = (realized_pnl_quote_units + unrealized_pnl_quote_units) * (hedge_quote / open_filled_quote_units) PnL хеджа на CEX, пересчитанный в quote.
PnL without hedge pnl_without_hedge_quote = dex_realized_il_quote + fees_received_quote + costs_quote Итог итерации без учёта результата CEX-хеджа.
PnL with hedge pnl_with_hedge_quote = pnl_without_hedge_quote + cex_pnl_quote Полный итог итерации с хеджем.
5) Dashboard
Показатель Формула Что означает
Active runs Количество run со статусом initialized/running/stopping Сколько запусков сейчас в работе.
Finished iterations sum(iterations_finished) Сумма завершённых итераций по всем run.
Total PnL with hedge sum(pnl_with_hedge_quote) Итоговый PnL с учётом hedge.
Total PnL without hedge sum(pnl_without_hedge_quote) Итоговый PnL без учёта hedge.
Total gas/costs PnL quote sum(costs_quote) Суммарный PnL-компонент издержек (обычно отрицательный).
APR with hedge (%) sum(apr_with_hedge_pct * total_quote) / sum(total_quote) Взвешенный APR с hedge.
APR without hedge (%) sum(apr_without_hedge_pct * total_quote) / sum(total_quote) Взвешенный APR без hedge.
Average APR per run (%) sum(apr_with_hedge_pct) / N Простой средний APR по запускам (без взвешивания на капитал).
Average iteration lifetime (sec) sum(avg_iteration_lifetime_sec where > 0) / N_positive Средняя длительность итерации по run с валидным временем.
6) Positions
Показатель Формула Что означает
PnL with hedge pnl_with_hedge_quote и (pnl_with_hedge_quote / total_quote) * 100 Доходность с учётом hedge.
PnL without hedge pnl_without_hedge_quote и (pnl_without_hedge_quote / total_quote) * 100 Доходность без hedge.
Fees fees_quote Сумма собранных комиссий LP.
Price PnL price_pnl_quote Результат от ценового движения в LP-части.
Hedge PnL hedge_pnl_quote Результат хеджа на CEX.
Gas/Costs PnL costs_quote = sum(costs_quote по итерациям run) PnL-компонент операционных издержек run (газ + комиссия ребаланса).
7) Run details: PnL-лестница
Показатель Формула
PnL: fees fees_received_quote
PnL: fees + il fees_received_quote + dex_realized_il_quote
PnL: fees + il + gas (fees + il) + costs_quote
PnL: fees + il + gas + cex (fees + il + gas) + cex_pnl_quote
APR: fees / fees+il / fees+il+gas / fees+il+gas+cex Для каждого уровня используется базовая формула APR с соответствующим PnL.
8) Iteration details
Показатель Формула Комментарий
PnL with hedge pnl_with_hedge_quote Итог итерации с hedge.
PnL without hedge pnl_without_hedge_quote Итог итерации без hedge.
APR with/without hedge Базовая формула APR с соответствующим PnL и pool_hold_seconds. Нормализация на год.
IL PnL quote dex_realized_il_quote Знак как у PnL: отрицательное значение = IL-убыток, положительное = IL-прибыль.
9) Практическая интерпретация знака
PnL > 0Прибыль.
PnL < 0Убыток.
APR > 0Положительная годовая доходность при текущей динамике.
APR < 0Отрицательная годовая доходность при текущей динамике.
